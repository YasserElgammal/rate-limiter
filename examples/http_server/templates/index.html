Available Endpoints

GET /api/data - Rate-limited API endpoint
Returns sample data if rate limit allows
GET /api/status - Check rate limit status
Returns current rate limit information without consuming a token

cURL Examples

# Check rate limit status
curl http://localhost:8080/api/status

# Test rate limiting (make 15 requests quickly)

  echo "Request $i:"
  curl -i http://localhost:8080/api/data
  echo ""
done
